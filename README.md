## Budget-Tracker Project
## Project Overview
 A simple budget tracker project developed using Python and Pandas.
## Objectives
  •  Load budget spending data
  
  •  Display expense records
  
  •  Calculate total expenditure
  
  •  Calculate department-wise spending
  
  •  View expenses
  
  ## Technologies & Tools used
  • Programming language: Python
  
  • Library: pandas (used for loading, filtering, and aggregating data)
  
  • Environment: Google Colab
